
# Robiul Islam Portfolio

A modern, responsive personal portfolio built with React, Tailwind CSS, and Lucide icons.

## Features
- **Boot-up Animation**: Custom terminal-style loader mimicking RobiulOS.
- **Dynamic Themes**: Switch between Dark/Light modes and multiple accent colors.
- **Interactive Gallery**: 3D perspective cards for project highlights.
- **Peace Mode**: Integrated Tilawat player with sound wave animations.
- **Responsive Design**: Optimized for mobile and desktop devices.

## How to Host on GitHub Pages
1. Create a new repository on GitHub.
2. Upload all files from this project (`index.html`, `index.tsx`, `App.tsx`, `constants.tsx`, `types.ts`, `metadata.json`) to the root of the repository.
3. Go to **Settings** > **Pages**.
4. Under **Build and deployment**, set the source to **Deploy from a branch**.
5. Select the `main` branch and `/root` folder, then click **Save**.
6. Your site will be live at `https://yourusername.github.io/your-repo-name/`.

## Note
This project uses **ES Modules** directly in the browser via `esm.sh`. No local build step (npm/yarn) is required to run or deploy the application.
